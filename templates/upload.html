Accepted File Formats & Guidelines

1. CSV File Specifications (.csv)

The system automatically searches for standard feedback column headers (case-insensitive):

feedback review comment text customer_feedback

* If none of these match, the first non-numeric column is automatically selected.

feedback "The delivery was swift and product quality outstanding!" "Item broken upon arrival. Demanding an urgent refund." "Good value for money. Packaging could be better."

2. Plain Text File Specifications (.txt)

A simple text file with one customer feedback entry per line. Empty lines are automatically ignored during parsing.

App crashes whenever I click checkout on Android. Customer representative Rahul was polite and fixed my issue. Received damaged goods after 2 weeks of delay!
Tip: After processing, each record is classified into Sentiment, Emotion, Category, and Priority and immediately added to your dashboard analytics and history.
