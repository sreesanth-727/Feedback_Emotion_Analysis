About FeedbackIQ

An intelligent, lightweight, open-source AI system designed to automatically ingest unstructured customer feedback, classify sentiment and emotional drivers, map issue categories, and triage urgency for immediate resolution.

1. Project Overview & Motivation

Modern consumer enterprises receive thousands of unstructured feedback items daily through customer support desks, product reviews, email surveys, and social channels. Manual review of these large volumes is inherently slow, subjective, and non-scalable, frequently resulting in critical customer grievances (such as double charges, shipping failures, or safety risks) getting lost in the queue.

FeedbackIQ solves this bottleneck by providing a locally deployable, completely open-source NLP and Machine Learning solution that operates with zero commercial API dependencies. It extracts actionable intelligence in milliseconds, prioritizing urgent negative tickets to protect customer trust and operational efficiency.

2. Four-Layer Modular Architecture (Report Chapter 3)

FeedbackIQ is structured into four decoupled layers adhering to clean separation of concerns, ensuring transparent data flow, reproducibility, and minimal memory footprint:

Layer 1

Presentation Layer

Responsive HTML5, modern CSS3 styling, vanilla JavaScript, and Chart.js dashboards. Provides KPI metrics cards, interactive sentiment doughnut charts, emotion frequency bars, category volumes, single-entry testing, and searchable audit logs.

Layer 2

Application Layer

Flask 3.x web server routing, HTTP request validation, file parsing for batch CSV and TXT streams, flash alert notifications, and orchestration services connecting endpoints with the ML and database layers.

Layer 3

NLP & Machine Learning Layer

Text preprocessing (normalization, punctuation cleaning, tokenization), TF-IDF sublinear vectorization (1–2 n-grams), balanced Logistic Regression classifiers, and the rule-based urgency triage inference engine.

Layer 4

Data Layer

Local SQLite database (feedback.db) ensuring ACID compliance and instant startup, serialized Scikit-learn model artifacts (Joblib), and training/sample data stores with zero external database server overhead.

3. Machine Learning & Classification Pipeline

The system utilizes a supervised machine learning pipeline engineered for high inference throughput, strong interpretability, and robust performance on noisy consumer texts:

  • Preprocessing & Normalization: Input feedback is stripped of HTML/special character noise, converted to lowercase, and normalized to remove extraneous whitespace while preserving emotional punctuation cues.
  • TF-IDF Feature Representation: Implemented via TfidfVectorizer(ngram_range=(1, 2), sublinear_tf=True). Sublinear term frequency scaling dampens the effect of repetitive tokens, while unigram and bigram extraction captures critical phrasing such as "not working", "charged twice", and "extremely good".
  • Logistic Regression Classifiers: Configured with class_weight='balanced' and max_iter=1000. Logistic Regression provides fast convergence, probabilistic confidence estimates, and high resilience against overfitting on sparse text matrices.
  • Multi-Dimensional Taxonomy:
    Sentiments: Positive, Neutral, Negative Emotions: Joy, Anger, Sadness, Fear, Surprise, Neutral Categories: Product Quality, Delivery, Customer Service, Payment, Pricing, Technical Issue, Refund / Return

4. Priority Triage Rules (Report Table 3.3)

Priority classification utilizes a deterministic hybrid rules engine combining sentiment, detected emotion, and urgent keyword triggers:

urgent refund broken charged twice never arrived fraud unacceptable 		Immediate Escalation: Route directly to on-call senior support / refund resolution tier within 1 hour.
⚡ MEDIUM Feedback classified as Negative Sentiment without acute urgency keywords or severe anger/fear triggers (e.g. minor delays, feature inconvenience). Standard SLA: Normal ticket review and response within standard operational hours (24–48 hours).
🟢 LOW Feedback classified as Positive or Neutral Sentiment (praise, suggestions, neutral product observations). Trend Monitoring: Ingested into long-term product analytics, NPS calculation, and feature roadmap tracking.
